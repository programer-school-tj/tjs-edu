# TJS Edu

Низоми рақамии идоракунии муассисаҳои таълимии Тоҷикистон.

## Се шакли истифода

- **Windows:** оғози маҳаллӣ бо Docker Desktop ва PostgreSQL дар компютер.
- **Интернетӣ:** ҳамон барнома дар сервери алоҳида бо домен ва HTTPS.
- **Мобилӣ:** PWA-и насбшаванда аз браузери Android/iPhone, бе сохтани барномаи алоҳида.

Дастури насб ва маҳдудиятҳои офлайн: [docs/DEPLOYMENT-AND-MOBILE.md](docs/DEPLOYMENT-AND-MOBILE.md).

Эзоҳ: Service Worker интерфейс ва файлҳои статикиро кеш мекунад. Ин ҳоло кафолати сабти ҳамаи маълумот бе интернет нест; барои ин бояд навбат/синхронизатсияи IndexedDB ба ҳамаи формаҳо пайваст ва санҷида шавад.


## Талабот
- Node.js 22 ё навтар (барои кори мустақими рушд)
- PostgreSQL 15 ё навтар
- Махзани маълумоти алоҳида барои TJS Edu

## Оғози маҳаллӣ бо Docker Desktop (Windows)
1. Docker Desktop ва WSL2-ро насб карда, Docker Desktop-ро кушоед.
2. ZIP-ро кушоед ва «ОҒОЗ-ДАР-WINDOWS.bat»-ро иҷро кунед.
3. Скрипт .env-и маҳаллиро бо калидҳои тасодуфии алоҳида месозад, PostgreSQL-ро оғоз мекунад, мигратсияҳоро иҷро мекунад ва веб/API-ро месозад.
4. Барнома дар http://localhost:8080 дастрас мешавад.
5. Барои қатъ кардан иҷро кунед: docker compose down.

Барои дидани сабтҳо: docker compose logs -f app.
Барои нусхаи эҳтиётии база: docker compose exec -T db pg_dump -U tjsedu tjs_edu > tjs-edu-backup.sql.

## Оғози рушд бе Docker
1. Вобастагиҳоро насб кунед: npm install.
2. Файли .env.example-ро ба .env нусха кунед ва DATABASE_URL ва SESSION_SECRET-ро пур кунед.
3. Барои базаи нав мигратсияро иҷро кунед: npm run db:migrate.
4. Барои оғоз кардани API ва веб якҷоя: npm run dev:all.

API дар порти 3001 кор мекунад. Санҷиши саломатӣ: http://localhost:3001/health.

## Амният
- Барои TJS Edu махзани мустақил созед. Маълумоти ProgramerTJ ё дигар лоиҳаҳоро истифода накунед.
- .env ва паролҳо/калидҳоро ба GitHub нафиристед.
- Танзимоти Docker барои кори маҳаллӣ порти 8080-ро танҳо ба localhost мебандад.
- Муассисаи нав бо ҳолати pending сабт мешавад; фаъолсозӣ бояд баъди тасдиқи маъмур анҷом ёбад.
- Пеш аз истеҳсол HTTPS, нусхаи эҳтиётии мунтазам, маҳдудкунии дархостҳои воридшавӣ ва сиёсати дастрасии муассисаҳоро танзим кунед.

## Мигратсияи база
Файли db/migrations/001_initial_schema.sql сохтори ибтидоиро месозад. Мигратсияҳои рақамгузоришуда бо тартиб иҷро мешаванд ва сабти иҷроиш дар tjs_edu_schema_migrations нигоҳ дошта мешавад.

## Насб кардани аввалин Super Admin
1. Аввал ҳисобро дар TJS Edu бо почтаи электронии худ сабт кунед.
2. Дар сервери боэътимод, ки ба базаи махсуси TJS Edu пайваст аст, иҷро кунед:
   npm run admin:promote -- email@example.com
3. Фармон танҳо ҳисоби мавҷударо ба нақши admin мегузаронад ва сессияҳои пешинаро бекор мекунад. Баъд аз он дубора ворид шавед.
4. Ин фармонро танҳо соҳиби дастрасии сервер иҷро кунад.
