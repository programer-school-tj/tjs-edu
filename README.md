# TJS Edu

Independent migration of the TJS Edu education-management platform from Floot.

## Migration principles
- Preserve the original Floot project until the independent version is verified.
- Preserve original Excel templates and formatting.
- Keep school data synchronized across devices.
- Support offline data entry and later synchronization.
- Do not invent official payroll or tariff values.

## Current status
Source inventory has begun. The application source, database schema, Excel templates, authentication, offline support, and end-to-end validation have not yet been fully migrated.
