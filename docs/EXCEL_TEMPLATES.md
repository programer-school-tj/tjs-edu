# Бланкҳои аслии Excel: тарификатсия ва табели маош

Ин ҳуҷҷат натиҷаи санҷиши файлҳои аслии аз ҷониби соҳиби лоиҳа пешниҳодшударо сабт мекунад. Ин ду файл сарчашмаи тарҳ мебошанд; онҳоро бо ҷадвали сохтаи нав иваз кардан мумкин нест.

## 1. Тарификатсия

- Файли аслӣ: `тарификатсия.xlsx`
- Варақ: `Лист1`
- Андоза: `A1:Z143` (26 сутун, 143 сатр)
- Ҳуҷайраҳои муттаҳидшуда: 82 диапазон
- Сатри 1: унвони муассиса ва моҳи/соли ҳисоботӣ
- Сатрҳои 2–4: сарлавҳаҳои бисёрсатҳа ва рақамгузории сутунҳо
- Ҷойҳои кормандон: 69 сабт, ҳар сабт дар ду сатри Excel (сатрҳои 5–142)
- Формулаҳои Excel дар нусхаи пешниҳодшуда нестанд.

## 2. Табели маош

- Файли аслӣ: `сафармад табел.xlsx`
- Варақ: `Лист1`
- Андоза: `A1:AD152` (30 сутун, 152 сатр)
- Самти чоп: landscape; андозаи коғаз дар файл A4 муқаррар шудааст.
- Ҳуҷайраҳои муттаҳидшуда: 223 диапазон
- Сатрҳои 1–4: унвон ва сарлавҳаҳои бисёрсатҳа
- Ҷойҳои кормандон: 69 сабт, ҳар сабт дар ду сатри Excel (сатрҳои 5–142)
- Сатрҳои охир барои ҷамъбаст ва имзои директор/муовини директор нигоҳ дошта мешаванд.
- Сутунҳои N, U, V, X, Y ва Z пинҳонанд.
- Формулаҳои Excel дар нусхаи пешниҳодшуда нестанд.

## 3. Қоидаҳои татбиқ дар TJS Edu

1. Файлҳои аслӣ ва ҳамаи диапазонҳои муттаҳидшуда, услубҳо, андозаи сатр/сутун ва танзимоти чоп бояд нигоҳ дошта шаванд.
2. Маълумоти кормандон аз рӯйхати кормандони муассиса гирифта мешавад; маълумоти тарификатсия ба табели моҳона манбаи асосӣ мешавад.
3. Ҳисобкуниҳои маош танҳо баъди ворид шудани меъёрҳо ва формулаҳои тасдиқшудаи расмӣ фаъол карда мешаванд. Формула аз рӯйи тахмин сохта намешавад.
4. Сатрҳои имзо ва ҷамъбасти табел набояд ҳамчун сатри корманд таҳрир шаванд.
5. Сутунҳои N–P ва X–AD-и табел то равшан шудани таъиноташон дастӣ/автоматӣ пур карда намешаванд.
6. Ҳоло ин ҳуҷҷат санҷиши сохтор аст; он маънои пайваст шудани файлҳои бинарӣ ба build-и мустақил ё санҷиши ҳисобкунии воқеиро надорад.

## 4. Формулаҳои Excel дар муҳаррири бланк

- Дар ҳуҷайраи таҳриршаванда формуларо бо аломати `=` оғоз кардан мумкин аст.
- Намунаҳо: `=J5*1.25`, `=ROUND(J5*1.25,2)`, `=SUM(K5:M5)`, `=IF(J5>0,J5*1.1,J5)`.
- Истинод ба ҳуҷайраҳо, қавс, амалҳои `+`, `-`, `*`, `/`, `^`, фоиз ва функсияҳои `SUM`, `ROUND`, `MIN`, `MAX`, `AVERAGE`, `ABS`, `IF` дастгирӣ мешаванд.
- Формула ҳамчун матни формула дар ҳуҷҷати муассиса сабт мешавад; муҳаррири дохилии TJS Edu натиҷаро ҳисоб мекунад ва ҳангоми содирот формулаи воқеии Excel ба файли `.xlsx` гузошта мешавад.
- Формулаҳои даврӣ, тақсим ба сифр, функсияҳои номаълум ва рамзҳои иҷрошавандаи JavaScript иҷозат дода намешаванд.
- Барои тағйири меъёри давлатӣ, фоиз ё музди асосӣ масъул метавонад формулаи ҳуҷайраро тағйир диҳад, масалан `=J5*(1+25%)`, ва файли Excel-ро содир кунад.

**Маҳдудияти муҳим:** формулаи воридшуда дар муҳаррири бланк ва файли Excel ҳисоб мешавад, аммо ҳоло худ аз худ сабти `institutionTariffs.monthlyBase`-ро иваз намекунад ва ба ҳисобкунии серверии табели маош интиқол намеёбад. Барои ин пайванди алоҳидаи тасдиқшаванда лозим аст: қоидаи маош бо санаи амал, фоиз, манбаи санад ва формулаи тасдиқшуда бояд ҳамчун танзимоти молиявии версиядор нигоҳ дошта шавад. То татбиқи он, формулаи бланк барои ҳисоб/содироти Excel аст, на манбаи ниҳоии пардохти корманд.
