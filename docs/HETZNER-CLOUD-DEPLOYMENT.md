# Нашри интернетии TJS Edu дар Hetzner Cloud

Ин дастур барои марҳилаи озмоишӣ аст. Сервери хурд барои санҷиши якчанд муассиса пешбинӣ мешавад; пеш аз зиёд кардани шумораи муассисаҳо бояд борсанҷӣ гузаронида, захираҳои сервер мувофиқи натиҷа зиёд карда шаванд.

## Тарҳи нашр

- Ubuntu Server 24.04 LTS.
- Docker Engine ва Docker Compose Plugin аз анбори расмии Docker.
- PostgreSQL 16 дар Docker volume-и маҳаллӣ.
- TJS Edu API ва интерфейс дар як контейнер.
- Caddy ҳамчун reverse proxy бо HTTPS-и автоматӣ.
- Порти барнома танҳо ба `127.0.0.1:8080` пайваст мемонад; танҳо Caddy аз интернет портҳои 80 ва 443-ро қабул мекунад.

**Муҳим:** то замоне ки домен, сервер, калидҳои махфӣ ва санҷиши барқарорсозии backup омода нашаванд, сайтро production эълон накунед. CI-и муваффақ танҳо санҷиши сохтмон ва тестҳоро тасдиқ мекунад.

## 1. Сервер ва домен

1. Дар Hetzner Cloud сервери Ubuntu 24.04 LTS созед. Барои пилоти ибтидоӣ CX23 (2 vCPU, 4 GB RAM) метавонад нуқтаи оғоз бошад, аммо иқтидори он барои 2000 муассиса кафолат дода намешавад.
2. Суроғаи IPv4-и серверро нигоҳ доред.
3. Дар идоракунии DNS сабти `A` барои домени худ созед, масалан `edu.example.tj`, ки ба IPv4-и сервер ишора кунад.
4. Пеш аз гирифтани сертификати TLS интизор шавед, ки DNS дуруст паҳн шавад.
5. Ба сервер танҳо бо SSH ва калиди шахсӣ ворид шавед. Воридшавии root бо паролро маҳдуд кунед ва навсозиҳои амниятиро насб кунед.

## 2. Firewall

Дар панели Hetzner Firewall ё firewall-и сервер танҳо ин портҳоро барои интернет иҷозат диҳед:

- TCP 22: SSH, беҳтараш танҳо аз IP-и маъмур.
- TCP 80: HTTP барои redirect ва гирифтани сертификат.
- TCP 443: HTTPS.

Порти PostgreSQL (5432) ва порти дохилии барнома (8080/3001) набояд аз интернет дастрас бошанд. Docker метавонад қоидаҳои UFW-ро убур кунад; қоидаҳои firewall-ро бо эҳтиёт санҷед ва ба тавсияҳои расмии Docker оид ба firewall пайравӣ кунед.

## 3. Docker ва Caddy

Docker Engine ва Compose Plugin-ро аз дастури расмии Ubuntu насб кунед:
https://docs.docker.com/engine/install/ubuntu/

Caddy-ро аз анбори расмии Ubuntu/Debian-и Caddy насб кунед:
https://caddyserver.com/docs/install

Пас аз насб санҷед:
```bash
sudo systemctl status docker
sudo systemctl status caddy
```

## 4. Гирифтани рамзи барнома

Пас аз ҳамроҳ шудани PR-и омодасозӣ ба `main`, рамзро ба сервер гиред:
```bash
sudo mkdir -p /opt/tjs-edu
sudo chown "$USER":"$USER" /opt/tjs-edu
git clone https://github.com/programer-school-tj/tjs-edu.git /opt/tjs-edu
cd /opt/tjs-edu
```

Агар директория аллакай мавҷуд бошад, ба ҷойи clone навсозии идорашавандаи Git-ро истифода баред. Ҳеҷ гоҳ файли `.env`-ро ба Git илова накунед.

## 5. Калидҳои махфӣ

Дар папкаи лоиҳа файли `.env` созед:
```bash
umask 077
cat > .env <<EOF
SESSION_SECRET=$(openssl rand -hex 48)
POSTGRES_PASSWORD=$(openssl rand -hex 32)
EOF
chmod 600 .env
```

Ин фармон танҳо ҳангоми сохтани аввалини муҳит иҷро шавад. Ҳангоми навсозӣ `.env`-и мавҷударо аз нав насозед, вагарна пароли база дигар мешавад. Калидҳоро ба касе нафиристед ва дар GitHub сабт накунед.

## 6. Caddy ва HTTPS

Файли `/etc/caddy/Caddyfile`-ро бо домени воқеии худ танзим кунед:
```caddy
edu.example.tj {
    encode zstd gzip
    reverse_proxy 127.0.0.1:8080
}
```

Пас аз иваз кардани домен:
```bash
sudo caddy validate --config /etc/caddy/Caddyfile
sudo systemctl reload caddy
```

Caddy баъди дуруст шудани DNS ва дастрас будани портҳои 80/443 сертификати HTTPS-ро автоматӣ мегирад. Дар браузер танҳо суроғаи HTTPS-ро истифода баред.

## 7. Оғози барнома

```bash
cd /opt/tjs-edu
docker compose up --build -d
docker compose ps
docker compose logs --tail=100 app db
curl --fail http://127.0.0.1:8080/health
```

Санҷиши беруна:
```bash
curl --fail https://edu.example.tj/health
```

Health check бояд ҷавоби муваффақ диҳад ва пайвасти база тасдиқ шавад. Сипас сабти аввалини корбарро анҷом дода, Super Admin-ро танҳо аз сервери боэътимод фаъол кунед:
```bash
docker compose exec app npm run admin:promote -- admin@example.tj
```
Ба ҷойи почтаи намунавӣ почтаи ҳисоби воқеии худатонро истифода баред.

## 8. Нусхаи эҳтиётӣ ва барқарорсозӣ

Нусхаи база бояд мунтазам ба ҷойи ҷудогона аз худи сервер интиқол дода шавад. Нусхае, ки танҳо дар ҳамон сервер нигоҳ дошта мешавад, ҳангоми вайроншавии сервер кофӣ нест.

Намунаи гирифтани dump:
```bash
mkdir -p /opt/tjs-edu/backups
chmod 700 /opt/tjs-edu/backups
docker compose exec -T db pg_dump -U tjsedu -d tjs_edu -Fc > /opt/tjs-edu/backups/tjs-edu-$(date +%F-%H%M).dump
```

Backup-ро рамзгузорӣ карда, ба нигаҳдории беруна интиқол диҳед. Барқарорсозиро дар муҳити алоҳида санҷед. То анҷоми санҷиши restore омодагии воқеии backup тасдиқ нашудааст.

## 9. Навсозӣ ва бозгашт

Пеш аз ҳар навсозӣ backup гиред. Сипас:
```bash
cd /opt/tjs-edu
git fetch origin
git checkout main
git pull --ff-only origin main
docker compose up --build -d
docker compose ps
docker compose logs --tail=100 app
```

Агар health check ноком шавад, барномаро барои истифодабарандагон дастнорас нигоҳ доред ва сабтҳоро санҷед. Мигратсияҳои база метавонанд тағйироти бозгаштнопазир дошта бошанд; пеш аз rollback нақшаи барқарорсозии база зарур аст.

## 10. Санҷишҳои ҳатмӣ пеш аз кушодани дастрасӣ ба мактабҳо

- Воридшавӣ, баромадан ва барқарорсозии парол.
- Нақшҳо ва ҷудокунии маълумоти муассисаҳо (tenant isolation).
- Сабт, таҳрир, несткунӣ ва чопи ҷадвали дарсӣ.
- Тарификатсия ва табели маош бо бланкҳои аслии Excel-и фармоишгар.
- Ҳисобҳои молиявӣ ва санҷиши иҷозатҳо.
- Санҷиши backup ва restore.
- HTTPS, cookie-и Secure, маҳдудкунии кӯшишҳои воридшавӣ, журналҳои аудит ва мониторинг.
- Санҷиши дастӣ дар Android ва Windows.
- Санҷиши офлайн барои ҳар як модул; ҳоло офлайн пурра кафолат дода нашудааст.
- Борсанҷӣ бо маълумоти сунъӣ пеш аз даъвати шумораи зиёди муассисаҳо.

## Вазъи ҳозира

Ин ҳуҷҷат нақшаи нашр аст, на далели он ки сервер харида ё барнома ба интернет бароварда шудааст. Барои анҷом додани нашри воқеӣ соҳиби лоиҳа бояд домен ва ҳисоби хостингро фароҳам кунад ва дастрасии серверро худаш идора намояд. Калидҳои махфӣ ва паролҳоро дар чат нафиристед.
