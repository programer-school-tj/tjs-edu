# TJS Edu: Roadmap аз аудит то нашри ниҳоӣ

Ин ҳуҷҷат нақшаи иҷрои лоиҳаи TJS Edu аз ҳолати кунунӣ то маҳсулоти мустақили омодаи истифода мебошад. Ҳуҷҷати асосии талабот `docs/PROJECT_SPEC.md` боқӣ мемонад; ин roadmap тартиби татбиқ ва меъёрҳои қабули марҳилаҳоро муайян мекунад.

## Қоидаҳои роҳбарии лоиҳа

1. Версияи аслии Floot то қабули ниҳоии версияи мустақил тағйир ё нест карда намешавад.
2. Ҳар муассиса tenant-и ҷудогона аст. Ҳар дархости API бояд иҷозати муассиса ва нақши корбарро дар сервер тафтиш кунад.
3. Қоидаҳои маош, андоз ва иловапулиҳо танҳо аз санадҳои расмии тасдиқшуда ворид мешаванд.
4. Қолабҳои аслии Excel аз нав сохта намешаванд; файли воқеӣ, формулаҳо, merge, андоза, чоп ва формат бояд санҷида шаванд.
5. Ҳар тағйирот бо typecheck, build ва санҷишҳои дахлдор тасдиқ мешавад.
6. Имконияти қисман сохташуда ҳамчун имконияти пурра нишон дода намешавад.
7. Нарху лимити FREE/PRO то тасдиқи соҳиблоиҳа ихтироъ карда намешавад.

## Нуқсонҳо ва хавфҳои муҳими ошкоршуда

### P0: бояд пеш аз истифодаи воқеии муассисаҳо ҳал шаванд

- Дар саҳифаҳои тарификатсия, маош ва ҷадвали дарсӣ се URL-и кӯҳнаи `/_cdn/static/...` аз Floot истифода мешавад. То пайдо ва ворид кардани файлҳои воқеии қолаб, ин пайвандҳо манбаи мустақил нестанд.
- Service worker танҳо shell ва файлҳои статикӣ-ро кэш мекунад. Сабти офлайн ва sync queue ҳанӯз татбиқ нашудааст.
- Лимити FREE дар `helpers/planQuota.tsx` ҳамчун 5 амалиёт дар ҳар модул собит аст, дар ҳоле ки талабот танзими он аз Super Admin мебошад.
- Баъзе foreign key-ҳои ҷадвалҳои синф, хонанда, корманд, тариф ва маош танҳо ба ID-и сабт ишора мекунанд, на ба ҷуфти ID + institution_id. Барои ҳифзи қатъии ҷудокунии муассисаҳо constraint-ҳои таркибӣ ва санҷишҳои иловагӣ заруранд.
- API-и муассисаҳо, кормандон ва дигар модулҳо бояд бо матритсаи ягонаи нақшҳо санҷида шавад; ҳоло баъзе endpoint-ҳо танҳо director/admin-ро месанҷанд.
- README фармони `npm run admin:promote`-ро нишон медиҳад, аммо скрипти `scripts/promote-admin.ts` дар tree-и ҷорӣ дида нашуд. Пеш аз истифодаи истеҳсолӣ ин фармон бояд ё амалӣ ё аз дастур хориҷ шавад.
- Тасдиқи бақайдгирии муассиса бояд дастрасии роҳбарро танҳо баъди тасдиқ фаъол кунад; ҳолати pending набояд ба маълумоти муассисаи дигар дастрасӣ диҳад.

### P1: бояд пеш аз нашри умумӣ ҳал шаванд

- Системаи тарҷума барои 5 забон.
- Ҳисоботи воқеӣ ва содироти Excel/PDF.
- Воридот/экспорти файлҳои аслӣ бо ҳифзи формулаҳо, merge, андоза ва саҳифабандӣ.
- Санҷишҳои автоматии API, tenant isolation, auth, payroll ва timetable.
- Backup/restore, аудит, маҳдудкунии дархостҳо ва сиёсати нигоҳдории маълумоти шахсӣ.
- Раванди барқарорсозии рамз бояд бо почтаи электронӣ ва маҳдудияти кӯшишҳо санҷида шавад.
- Ҳолати Android ва Desktop ҳамчун бастаи воқеии насбшаванда омода карда шавад.

## Тартиби иҷро аз 0 то анҷом

### Марҳилаи 0. Мустаҳкам кардани асос ва аудит
- Баррасии тамоми endpoint-ҳо, schema, нақшҳо ва хатогиҳои build.
- Яксон кардани ҷавобҳои API, validation, logging ва error handling.
- Ислоҳи дастурҳои кӯҳна ва фармонҳои номувофиқ.
- Иловаи санҷишҳои автоматии асосӣ.
**Қабул:** build ва typecheck сабз; API-ҳои асосӣ санҷида мешаванд; ҳуҷҷатҳои иҷро бо код мувофиқанд.

### Марҳилаи 1. Амният ва бисёрмуассисавӣ
- Матритсаи Super Admin / director / teacher / staff.
- Санҷиши иҷозат дар ҳар endpoint, на танҳо дар интерфейс.
- Foreign key ва unique constraint-ҳои таркибӣ бо institution_id.
- Санҷиши кӯшиши дастрасӣ ба ID-и муассисаи дигар.
- Session, password reset, rate limit, audit log ва backup.
**Қабул:** санҷишҳои манфии cross-tenant ва нақшҳо гузаранд.

### Марҳилаи 2. Маълумоти ибтидоии муассиса
- Муассиса, кормандон, хонандагон, синфҳо ва соли таҳсил.
- Профили пурраи корманд ва таърихи вазифа/сарборӣ.
- Роҳбари синф, гурӯҳ ва гузариши хонанда.
**Қабул:** маълумот ворид, таҳрир, ҷустуҷӯ, ғайрифаъол ва чоп шавад.

### Марҳилаи 3. Тарификатсия
- Ворид кардани қолаби аслии Excel.
- Пайвасти тариф ба корманд, таҳсилот, ихтисос, категория, соат ва вазифа.
- Сабти манбаи санад ва муҳлати амал.
- Формулаҳо танҳо баъди тасдиқи санадҳои расмӣ.
**Қабул:** натиҷа бо бланки аслӣ ва ҳисобкунии дастии назоратӣ мувофиқат кунад.

### Марҳилаи 4. Табели маош
- Пайваст кардани маош ба тарифи тасдиқшуда ва корманд.
- Моҳ, иловапулӣ, нигоҳдошт, маблағи умумӣ ва маблағи пардохт.
- Таърихи ҳисоб, тасдиқ ва ислоҳи сабт.
- Имкони бастани моҳи ҳисоботӣ.
**Қабул:** санҷиши ҳисоб бо намунаҳои расмӣ; ҳеҷ қоидаи тахминӣ ҳамчун қонун истифода нашавад.

### Марҳилаи 5. Ҷадвали дарсӣ
- Пайвасти омӯзгор, фан, синф, сарборӣ, баст ва кабинети дарсӣ.
- Қоидаҳои 6 рӯзи таҳсил, маҳдудияти дарсҳои рӯзона ва бастҳо.
- Пешгирии бархӯрди омӯзгор, синф ва кабинет.
- Алгоритми тақсимоти худкор бо нишон додани сабаби ҷойгир нашудани соат.
- Таҳрири дастӣ ва қулф кардани дарсҳои тасдиқшуда.
**Қабул:** ҷадвали намунавии МТМУ №14 аз санҷиши ҳамаи конфликтҳо гузарад.

### Марҳилаи 6. Excel, ҳуҷҷатҳо ва чоп
- Ворид кардани файлҳои воқеии се қолаб ба assets-и маҳаллӣ.
- Санҷиши формула, формат, merge, андозаи сатр/сутун ва print area.
- Импорт/экспорт ва нигоҳдории версияи ҳуҷҷат.
- PDF ва чопи A4/landscape/portrait.
**Қабул:** файлҳои баромад бо қолаби аслӣ муқоиса ва тасдиқ шаванд.

### Марҳилаи 7. Модулҳои умумӣ
- Attendance-и хонанда ва корманд.
- Маводи таълимӣ ва китобхона.
- Dashboard ва ҳисоботҳо.
- Кӯмак ва дастурҳои роҳбар/омӯзгор.
**Қабул:** ҳар ҳисобот аз маълумоти воқеии пойгоҳ сохта шавад ва филтр/экспорт кор кунад.

### Марҳилаи 8. FREE/PRO ва Super Admin
- Танзими лимит аз база ва панели маъмур.
- Танзими дастрасии модулҳо, нарх ва муҳлат танҳо баъди тасдиқи соҳиблоиҳа.
- Омори истифода, таърихи тағйири нақша ва audit.
**Қабул:** тағйири лимит бе нашри нави код амал кунад.

### Марҳилаи 9. Забонҳо ва тарҳи ниҳоӣ
- Тарҷумаҳои тоҷикӣ, русӣ, англисӣ, ӯзбекӣ ва форсӣ.
- Логотипи тасдиқшуда ва маҷмӯи тасвирҳои сабуки дохилӣ.
- Мутобиқсозӣ барои телефон, планшет ва компютер.
- Санҷиши дастрасӣ, контраст ва истифода бо клавиатура.
**Қабул:** тамоми саҳифаҳо дар ҳар панҷ забон бе матни омехта кор кунанд.

### Марҳилаи 10. Offline-first ва ҳамоҳангсозӣ
- IndexedDB барои маълумоти маҳаллии иҷозатдодашуда.
- Навбати тағйирот бо идентификатори беназир ва retry-и бехатар.
- Нишон додани pending/synced/failed.
- Ҳалли conflict ва ҳифзи маълумоти ҳассос дар дастгоҳ.
**Қабул:** санҷиши воқеӣ бо қатъи интернет, бастани браузер, бозкушоӣ ва sync бе сабти такрорӣ гузарад.

### Марҳилаи 11. Нашр ва супоридани лоиҳа
- Хостинги мустақил, HTTPS, домен ва махзани алоҳида.
- Мониторинг, backup ва барқарорсозии санҷидашуда.
- PWA install, бастаи Android ва версияи Desktop дар ҳолати зарурат.
- Дастури насб/истифода ва ZIP-и пурраи манбаъ.
**Қабул:** рӯйхати санҷиши ниҳоии PROJECT_SPEC пурра иҷро шуда, нусхаи маҳаллӣ ба соҳиблоиҳа супорида шавад.

## Маълумоте, ки бояд аз соҳиблоиҳа ворид шавад

- Се файли аслии Excel: тарификатсия, табели маош ва ҷадвали дарсӣ.
- Санадҳои расмии амалкунандаи маош, андоз, иловапулиҳо ва нигоҳдошт.
- Тасдиқи нарх ва лимитҳои FREE/PRO.
- Тасдиқи ниҳоии логотип ва матнҳои тарҷума, агар тағйир лозим шавад.

## Ҳолати нашр

То иҷрои ҳамаи марҳилаҳо TJS Edu ҳамчун **версияи рушдёбанда** ҳисобида мешавад. Ҳеҷ гоҳ танҳо бо сабаби сабз шудани CI онро омодаи истифодаи воқеии муассисаҳо эълон накунед.
