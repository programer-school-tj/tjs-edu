# TJS Edu: Master Project Specification

**Низоми рақамии идоракунии муассисаҳои таълимии Тоҷикистон**

- **Номи лоиҳа:** TJS Edu
- **Муаллиф ва таҳиягар:** Тоҷиддинов Сафармад Ҷамолиждинович
- **Вазифа:** Омӯзгори фанни технологияи иттилоотӣ
- **Муассиса:** МТМУ №14
- **Самти фаъолият:** Идоракунии рақамии муассисаҳои таълимӣ
- **Забони асосӣ:** тоҷикӣ
- **Платформаҳо:** Web, Android ва компютер
- **Тарзи истифода:** онлайн ва офлайн
- **Шиор:** «Маориф дар як низом, идоракунӣ дар як платформа.»

Ин ҳуҷҷат талаботи асосӣ ва меъёри қабул барои рушди TJS Edu мебошад. Он талаботи пурраи дархосткунандаро нигоҳ медорад. Амалӣ кардани лоиҳа марҳила ба марҳила сурат мегирад; то замони санҷиши воқеӣ ягон имконият ҳамчун анҷомёфта эълон карда намешавад.

## 1. Мақсади асосӣ ва доираи муассисаҳо

TJS Edu низоми ягонаи рақамӣ барои идоракунӣ ва автоматикунонии фаъолияти муассисаҳои таълимии Ҷумҳурии Тоҷикистон аст. Ҳадаф кам кардани кори дастӣ, осон кардани ҳуҷҷатгузорӣ, нигоҳдории маълумот, ҳисобу китоб ва назорати фаъолияти муассиса мебошад.

Низом бояд барои муассисаҳои таҳсилоти миёнаи умумӣ (МТМУ), литсейҳо, гимназияҳо, коллеҷҳо, донишкадаҳо ва донишгоҳҳо дастрас бошад. Аз рӯзи оғози истифода муассисаи дилхоҳ бояд тавонад ба низом пайваст шавад. Барои оғози лоиҳа харидани сервери шахсӣ шарт нест; ҷойгиркунии аввалия дар хидмати абрии мувофиқ бо имкони кӯчонидан ба сервери шахсӣ пешбинӣ мешавад.

## 2. Сатҳҳои дастрасӣ

### 2.1 Super Admin
- Дидани ҳамаи муассисаҳои пайвастшуда.
- Илова, таҳрир ва ғайрифаъол кардани муассисаҳо.
- Назорати истифодабарандагон.
- Идоракунии FREE ва PRO.
- Назорати фаъолияти низом ва омори умумӣ.
- Идоракунии лимитҳо, иҷозатҳо, амният ва ҳолати сервер.

### 2.2 Роҳбар ё директори муассиса
- Идоракунии кормандон, хонандагон ва синфҳо.
- Ташкили ҷадвали дарсӣ.
- Кор бо тарификатсия ва ҳисоб кардани маош.
- Нигоҳдории ҳуҷҷатҳо ва дидани ҳисоботҳо.
- Идоракунии дастрасии омӯзгорон ва кормандон.

### 2.3 Омӯзгор ва корманд
- Дидани маълумоти шахсӣ ва вазифавӣ.
- Дидани ҷадвали дарсӣ.
- Кор бо маводи таълимӣ.
- Дидани маълумоти марбут ба фаъолияти худ.
- Истифодаи ҳуҷҷатҳое, ки роҳбар иҷозат додааст.

## 3. Модулҳои низом

### 3.1 Панели асосӣ
Номи муассиса, нишондиҳандаҳои умумӣ, шумораи омӯзгорон/кормандон, хонандагон ва синфҳо, огоҳиномаҳо, ҳолати пайвастшавӣ ва омори мухтасар.

### 3.2 Муассисаҳо
Бақайдгирии муассисаи нав; ном, навъ, суроға, тамос, роҳбар ва маълумоти зарурӣ; таъйини FREE/PRO ва идоракунии ҳолати муассиса.

### 3.3 Кормандон
Илова ва таҳрири корманд; ном ва насаб, маълумоти шахсӣ, таҳсилот, ихтисос, вазифа, собиқа, санаи қабул, тамос ва ҳолати фаъолият; ҷустуҷӯ, филтр ва чоп.

### 3.4 Хонандагон
Маълумоти шахсӣ, синф/гурӯҳ, соли таҳсил, падару модар ё намояндаи қонунӣ, вазъи таҳсил, гузариш ба синфи дигар, ҷустуҷӯ, филтр ва чопи рӯйхат.

### 3.5 Синфҳо
Иловаи синф бо рақам ва ҳарф, таъйини роҳбари синф, пайваст кардани хонандагон ва омӯзгорон, намоиши рӯйхати хонандагон.

### 3.6 Ҷадвали дарсӣ
Интихоби синф, омӯзгор, фан, рӯз ва соати дарс; пешгирии бархӯрди ҳамзамони синф ва омӯзгор; таҳрир, чоп, воридот аз Excel ва нигоҳдорӣ барои ҳар соли таҳсил.

### 3.7 Тарификатсия
Ворид кардани маълумоти тарификатсионӣ, омӯзгор, ихтисос, таҳсилот, категорияи тахассусӣ, соатҳои ҳафтаина, вазифа, сарборӣ, иловаҳо ва пардохтҳои дахлдор; нигоҳдорӣ, чоп ва содирот ба Excel. Шаблони аслии тарификатсия, формулаҳо, формат ва сохтори он бояд нигоҳ дошта шаванд.

### 3.8 Ҳисобкунии маош
Ҳисоб аз рӯйи тарификатсия, вазифа ва сарборӣ; иловаҳои муқарраршуда; нигоҳдории ҳисобҳои моҳона; ҳисоботи кормандон; чоп ва содирот ба Excel. Меъёрҳои маош, андоз ва пардохтҳо танҳо аз ҳуҷҷатҳои расмии амалкунанда гирифта мешаванд. Маблағ ё формулаи тахминӣ набояд ҳамчун меъёри расмӣ нишон дода шавад.

### 3.9 Ҳозиршавӣ
Сабти ҳозиршавии кормандон ва хонандагон, сабабҳои иштирок накардан, ҷустуҷӯ аз рӯйи сана ва синф, ҳисоботи рӯзона/моҳона ва чоп.

### 3.10 Маводи таълимӣ
Иловаи китобу ҳуҷҷатҳо, боркунии PDF ва дигар файлҳои иҷозатдодашуда, гурӯҳбандӣ аз рӯйи фан ва синф, дастрасӣ барои шахсони иҷозатдор, ҷустуҷӯ ва зеркашӣ.

### 3.11 Ҳисоботҳо
Ҳисоботи кормандон, хонандагон, синфҳо, ҳозиршавӣ, ҷадвали дарсӣ, маош ва тарификатсия; филтр аз рӯйи сана/давра; чоп ва содирот ба Excel ё PDF.

### 3.12 Ҳуҷҷатҳо ва бланкаҳо
Боркунии бланкаҳои Excel, кушодан ва пур кардан, нигоҳдории маълумоти воридшуда, идомаи таҳрир, чоп ва содирот ба Excel. Формулаҳо ва тарҳи аслии бланка бояд ҳифз шаванд.

### 3.13 Кӯмак ва дастур
Дастури истифода, шарҳи вазифаи бахшҳо, саволу ҷавоб, дастури роҳбар ва омӯзгор, маълумоти тамос.

## 4. FREE ва PRO

Ҳар ду версия нигоҳ дошта мешаванд. FREE барои истифодаи асосӣ ва PRO барои имкониятҳои васеъ, аз ҷумла ҳисоботҳои муфассал, имкониятҳои васеи Excel, идоракунии мукаммали ҳуҷҷатҳо, омори иловагӣ ва функсияҳои иловагии муассиса пешбинӣ шудааст.

Лимитҳои дақиқ, нархи обуна ва ҷадвали фарқиятҳо ҳоло тасдиқ нашудаанд. Онҳо бояд аз панели Super Admin танзимшаванда бошанд. То тасдиқи соҳиблоиҳа нарх ё лимити нав ихтироъ карда нашавад.

## 6. Амният ва ҳифзи маълумот

Воридшавӣ бо почтаи электронӣ/номи корбар ва рамз; сабти истифодабарандагон; барқарорсозии рамз; идоракунии иҷозатҳо; ҷудокунии маълумоти муассисаҳо; муҳофизати API; санҷиши иҷозати ҳар амалиёт; audit log; ҳифзи маълумоти шахсӣ; маҳдуд кардани кӯшишҳои нодурусти воридшавӣ. Сирҳо, паролҳо ва калидҳо набояд дар GitHub нигоҳ дошта шаванд.

## 7. Онлайн, офлайн ва PWA

Барнома ҳамчун PWA кор кунад. Онлайн: маълумот ба сервер фиристода шуда, тағйирот дар дастгоҳҳои иҷозатдор дастрас гардад ва ҳолати синхронизатсия нишон дода шавад. Офлайн: қисмҳои қаблан боршуда кушода шаванд; маълумоти иҷозатдодашуда маҳаллӣ нигоҳ дошта шавад; амалиётҳо ба навбат гузошта шаванд; пас аз барқарор шудани интернет синхронизатсия бо назорати ҳолати фиристодан, хатогӣ ва такрори бехатар иҷро шавад. Кэшкунии саҳифа танҳо маънои офлайн-кори пурраи CRUD-ро надорад.

## 8. Тарҳи зоҳирӣ ва логотип

Тарҳи замонавӣ ва касбӣ барои соҳаи маориф. Логотип бояд бинои мактаб, парчами Тоҷикистон, ҳарфҳои «Т.С.», тоҷ ва ҳафт ситораро бо услуби муосир ва 3D-и нозук дар бар гирад. Рангҳо: кабуди тира, сурх, сабз ва сафед.

Тасвирҳои дохилӣ бо услуби ягона: саҳифаи асосӣ (мактаб ва парчам), омӯзгор (омӯзгор назди тахтаи электронӣ), хонандагон (китобу ноутбук), дарсҳо (компютер ва технология), ҳисоботҳо (диаграмма), китобхона (китобҳои электронӣ). Тасвирҳо сабук ва барои телефон мутобиқ бошанд.

## 9. Меъмории техникӣ

Меъмории пешбинишуда:
- React + TypeScript барои интерфейс.
- CSS барои тарҳ.
- Vite барои build.
- Supabase ва PostgreSQL барои база, аутентификатсия ва сиёсати дастрасӣ.
- ExcelJS барои хондану таҳрири Excel.
- PWA барои насб дар телефон ва компютер.
- IndexedDB барои нигоҳдории муваққатӣ ва навбати офлайн.

Ин меъморӣ ҳадафи кӯчонидан аст. Технологияҳои воқеан истифодашуда ва қисмҳои ҳанӯз амалӣнашуда бояд дар ҳуҷҷатгузорӣ дақиқ нишон дода шаванд. Пайваст кардани база ё хидмати нав бе тасдиқи соҳиблоиҳа анҷом дода нашавад.

## 10. Бланкаҳои Excel

Се қолаби аслӣ мавҷуд буданд: тарификатсия, табели маош ва ҷадвали дарсӣ. Онҳо бояд бо формулаҳо, андозаи сутунҳо/сатрҳо, формат ва сохтори аслӣ нигоҳ дошта шаванд. Ҳангоми кӯчонидан аз Floot URL-и кӯҳна набояд ҳамчун манбаи мустақили доимӣ боқӣ монад; файлҳои воқеӣ бояд ба дороиҳои лоиҳа гузаронида ва санҷида шаванд.

## Қоидаҳои иҷро ва тартиби афзалият

- Бланкҳои аслӣ бе иҷозати соҳиблоиҳа аз нав тарҳрезӣ ё бо маълумоти сохта пур карда намешаванд.
- Қоидаҳои маошу андоз танҳо бо санади расмии тасдиқшуда ворид карда мешаванд.
- Ҳар тағйирот бояд дар GitHub сабт, build/typecheck санҷида ва натиҷаи воқеӣ гузориш дода шавад.
- Имконияте, ки танҳо қисман сохта шудааст, ҳамчун пурра анҷомёфта нишон дода нашавад.
