# Дастури насб барои Windows 10 ва Windows 11

TJS Edu барои ҳар ду система аз як бастаи ягона истифода мебарад. Барномаи алоҳида ё версияи дигар лозим нест.

## Windows 10

Талаботи тавсияшаванда:
- Windows 10 версияи 22H2, 64-bit
- WSL 2 фаъол
- Docker Desktop бо backend-и WSL 2
- RAM аз 8 GB тавсия мешавад (4 GB метавонад суст бошад)
- Фазои холии диск барои Docker, тасвирҳо ва базаи маълумот

Қадамҳо:
1. Windows Update-ро иҷро карда, Windows 10-ро ба 22H2 нав кунед.
2. WSL 2 ва Docker Desktop-ро насб кунед.
3. Docker Desktop-ро кушоед ва интизор шавед, ки ҳолаташ Running шавад.
4. ZIP-и TJS Edu-ро кушоед.
5. Файли `ОҒОЗ-ДАР-WINDOWS.bat`-ро ду маротиба пахш кунед.
6. Пас аз паёми муваффақият ба `http://localhost:8080` гузаред.

## Windows 11

Талабот:
- Windows 11, 64-bit
- WSL 2 фаъол
- Docker Desktop бо backend-и WSL 2
- RAM аз 8 GB тавсия мешавад
- Фазои холии диск барои Docker ва база

Қадамҳо:
1. WSL 2 ва Docker Desktop-ро насб кунед.
2. Docker Desktop-ро кушоед ва интизор шавед, ки ҳолаташ Running шавад.
3. ZIP-и TJS Edu-ро кушоед.
4. Файли `ОҒОЗ-ДАР-WINDOWS.bat`-ро ду маротиба пахш кунед.
5. Пас аз паёми муваффақият ба `http://localhost:8080` гузаред.

## Санҷиши пешакӣ

PowerShell-ро кушоед ва фармонҳои зеринро иҷро кунед:

```powershell
winver
wsl --status
docker version
docker compose version
```

Агар `docker version` ё `docker compose version` хато диҳад, Docker Desktop ҳанӯз дуруст насб ё оғоз нашудааст.

## Муҳим

- Windows 10-и кӯҳна ё 32-bit метавонад бо версияҳои навини Docker Desktop мувофиқ набошад. Windows 10 22H2 64-bit-ро истифода баред.
- Файли оғози умумӣ барои Windows 10 ва 11 як аст, зеро ҳар ду аз ҳамон Docker Compose истифода мебаранд.
- Барои истифодаи маҳаллӣ интернет метавонад барои боргирии аввалини Docker image ва вобастагиҳо лозим шавад.
- Баъд аз насби аввал, кори маҳаллӣ аз интернет вобаста нест, ба шарте ки ҳамаи image-ҳо бор шуда бошанд.
- Барои нигоҳ доштани маълумот `docker compose down` истифода кунед. Фармони `docker compose down -v` ҳаҷми базаи маҳаллиро нест мекунад.
- Скрипти оғози нав танзимоти дигари `.env`-ро нигоҳ медорад ва танҳо калидҳои зарурии нодуруст ё гумшударо месозад.

Агар ҳангоми насб мушкилӣ пайдо шавад, дастури [бартараф кардани мушкилот](WINDOWS-TROUBLESHOOTING.md)-ро хонед.
