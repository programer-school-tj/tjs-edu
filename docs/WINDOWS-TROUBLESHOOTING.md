# Бартараф кардани мушкилоти TJS Edu дар Windows

Ин дастур барои Windows 10/11 ва оғози маҳаллӣ бо Docker Desktop аст.

## 1. Пеш аз оғози барнома

PowerShell-ро кушоед ва санҷед:

```powershell
wsl --status
docker version
docker compose version
```

Дар Docker Desktop ҳолати **Running** бояд намоён бошад. Агар `docker version` танҳо маълумоти Client нишон диҳад ё Server error диҳад, муҳаррики Docker ҳанӯз фаъол нест.

## 2. Хатои порт 8080

Агар паём дар бораи он гӯяд, ки порт аллакай истифода мешавад, дар PowerShell иҷро кунед:

```powershell
netstat -ano | findstr :8080
```

Раванди истифодакунандаи портро муайян кунед. Онро танҳо баъди муайян кардани барномаи мувофиқ қатъ намоед. Ё порти маҳаллиро дар `docker-compose.yml` тағйир диҳед ва баъд аз нав оғоз кунед.

## 3. Барнома кушода намешавад ё санҷиши health ноком мешавад

Дар папкаи TJS Edu иҷро кунед:

```powershell
docker compose ps
docker compose logs --tail 150 db app
```

- Агар базаи `db` healthy набошад, сабтҳои `db`-ро санҷед.
- Агар `app` қатъ шавад, сабтҳои `app` сабаби хатогиро нишон медиҳанд.
- Баъди ислоҳи сабаб иҷро кунед: `docker compose up --build -d`.

## 4. Нусхаи эҳтиётии маълумот

Пеш аз навсозӣ ё интиқоли компютер нусха гиред:

```powershell
docker compose exec -T db pg_dump -U tjsedu tjs_edu > tjs-edu-backup.sql
```

Файли `tjs-edu-backup.sql`-ро дар ҷои амн нигоҳ доред. Барои барқароркунӣ, аввал базаи холии мувофиқро омода карда, баъд SQL-ро ворид кунед; пеш аз барқароркунӣ нусхаи ҷории маълумотро низ нигоҳ доред.

## 5. Фармонҳои бехатар

- Қатъ кардан бе нест кардани маълумот: `docker compose down`
- Аз нав оғоз кардан: `docker compose up -d`
- Дидани ҳолат: `docker compose ps`
- Дидани сабтҳо: `docker compose logs -f app`

**Огоҳӣ:** `docker compose down -v` volume-и базаи маҳаллиро нест мекунад. Ин фармонро истифода накунед, агар қасдан тамоми маълумоти маҳаллиро пок кардан нахоҳед.

## 6. Маҳдудияти истифода

Ин насб танҳо дар ҳамон компютер бо суроғаи `http://localhost:8080` дастрас аст. Барои дастрасӣ аз компютерҳои дигар ё интернет сервер, HTTPS, firewall, нусхаҳои эҳтиётӣ ва санҷиши амният лозиманд.

Кеш шудани интерфейс дар браузер маънои онро надорад, ки ҳамаи формаҳо бе интернет маълумотро сабт ва баъд синхрон мекунанд. То анҷоми санҷишҳои end-to-end воридкунии пурраи офлайнро кафолат додан мумкин нест.
