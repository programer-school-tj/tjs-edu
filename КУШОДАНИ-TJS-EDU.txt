TJS EDU — ДАСТУРИ ОҒОЗ ДАР WINDOWS

Муҳим: ин ZIP барномаи Android ё файли HTML-и мустақил нест. Барои кори пурра компютери Windows, Docker Desktop ва пайвасти интернет барои боргирии тасвирҳои аввалия лозим аст.

1. ZIP-ро пурра Extract кунед.
2. Docker Desktop-ро насб кунед ва кушоед (WSL2 фаъол бошад).
3. Файли «ОҒОЗ-ДАР-WINDOWS.bat»-ро ду бор пахш кунед.
4. Интизор шавед, то Docker тасвирҳоро боргирӣ ва барномаро созад.
5. Дар браузер кушоед: http://localhost:8080

Базаи PostgreSQL дар volume-и Docker нигоҳ дошта мешавад. Барои қатъ кардани барнома дар дохили ҳамин папка фармони:
docker compose down

Барои дидани сабтҳои хатогӣ:
docker compose logs -f app

Барои пок кардани тамоми маълумоти база (эҳтиёт!):
docker compose down -v

Ин амал маълумоти базаи маҳаллиро нест мекунад. Пеш аз он нусхаи эҳтиётӣ гиред.

Агар барнома кушода нашавад, матни хатои равзанаи PowerShell/Docker-ро фиристед.
