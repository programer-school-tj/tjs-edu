TJS EDU — ДАСТУРИ ОҒОЗ ДАР WINDOWS

Талабот:
- Windows 10/11 бо WSL2
- Docker Desktop насб ва фаъол
- Интернет барои боргирии тасвири PostgreSQL ва вобастагиҳои сохтмонӣ

Оғоз:
1. ZIP-ро пурра Extract кунед.
2. Docker Desktop-ро насб кунед ва кушоед.
3. Файли «ОҒОЗ-ДАР-WINDOWS.bat»-ро ду бор пахш кунед.
4. Скрипт .env-и маҳаллӣ бо калидҳои тасодуфии алоҳида месозад, PostgreSQL-ро оғоз мекунад, 11 мигратсияи база ва барномаро месозад.
5. Вақте паёми «TJS Edu фаъол аст» пайдо шуд, дар браузер кушоед: http://localhost:8080

Идора:
- Қатъ кардан: docker compose down
- Аз нав оғоз кардан: docker compose up -d
- Дидани сабтҳо: docker compose logs -f app
- Нусхаи эҳтиётии база: docker compose exec -T db pg_dump -U tjsedu tjs_edu > tjs-edu-backup.sql

Муҳим:
- Маълумоти база дар volume-и Docker нигоҳ дошта мешавад.
- «docker compose down -v» тамоми маълумоти маҳаллиро нест мекунад. Бе нусхаи эҳтиётӣ ин фармонро истифода накунед.
- Порти 8080 танҳо барои ҳамин компютер (localhost) кушода аст. Барои дастрасӣ аз интернет сервери дорои HTTPS ва танзимоти иловагии амният лозим аст.
- Агар оғоз нашавад, матни хатои равзана ё натиҷаи «docker compose logs --tail 100 app db»-ро фиристед.
